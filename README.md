# Моделирование рельефа и линий водостока

Учебный проект: загрузка GeoTIFF, вычисление градиента и уклонов,
построение линий водостока методом градиентного спуска.

## Установка и запуск

Нужен Python 3.11+. В терминале из папки проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Без параметров создаётся искусственная чаша: линии должны сходиться к её центру.
В репозитории есть пример реального рельефа `relief.tif`. Запуск:

```powershell
.\.venv\Scripts\python.exe main.py --dem relief.tif
```

Результат — `outputs/terrain.png`: слева высоты и голубые линии водостока,
белые точки обозначают их начало; справа уклоны в градусах.
Другую папку можно указать через `--out outputs/real`.
Для своего участка замените имя файла после `--dem`.

## Как работает

1. Rasterio читает первый канал GeoTIFF как матрицу высот. Высоты должны быть
   в метрах; пропуски сохраняются. При необходимости сетка переводится в метрическую проекцию.
2. NumPy вычисляет производные по соседним высотам с учётом размеров ячейки.
   Уклон равен arctan длины градиента и переводится в градусы.
3. Из девяти начальных точек строятся траектории против градиента.
   Точки выбираются через равные промежутки в списке ячеек с известным градиентом
   (список идёт по строкам). Это демонстрационные точки, а не найденные истоки рек.
   Между ячейками значения оцениваются билинейной интерполяцией SciPy.
   Если высота не уменьшается, шаг сокращается вдвое.
4. Matplotlib соединяет рассчитанные точки линиями и сохраняет рисунок.

Линии описывают геометрические пути спуска. Расчёт скорости воды, D8,
накопление стока и обработка впадин пока не реализованы.

## Файлы и проверки

- `main.py` — загрузка, математика и рисунок.
- `test_main.py` — проверки плоскости, чаши, ровной поверхности и чтения GeoTIFF.
- `requirements.txt` — зависимости.
- `relief.tif` — пример для совместной работы.

Pytest необязателен для запуска программы. Для проверок установите его отдельно:

```powershell
.\.venv\Scripts\python.exe -m pip install pytest
.\.venv\Scripts\python.exe -m pytest test_main.py -q
```

Результаты, локальное окружение и другие GeoTIFF не включаются в репозиторий.
Исходный источник и условия использования примера relief.tif пока не записаны.
Без параметров программа сама создаёт тестовый файл; реальные DEM можно искать на
[OpenTopography](https://portal.opentopography.org/datasets).
